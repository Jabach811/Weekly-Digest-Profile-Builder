# Exports Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the `exports/` family — four on-demand HTML dumps (caseload snapshot, projects portfolio, single-project deep dive, OOO hand-off pack) compiled from the persistent-brain markdown files, reusing the weekly brief's retro-console design.

**Architecture:** No generator script, no templates, no build pipeline. A canonical `exports/_skeleton.html` carries the full CSS and component examples. Each export is produced by copying the skeleton, filling it with content compiled from the relevant markdown sources, and saving to a date-stamped filename in `exports/`. Single-page, single-file, self-contained.

**Tech Stack:** Static HTML + CSS (inlined). Python 3 `http.server` for local preview (configured in `.claude/launch.json`). No JavaScript runtime, no frameworks, no build step.

**Context notes:**
- This project is not a git repo (per session environment). "Commit" steps below are replaced with "verify" steps — open each output in the browser and confirm it matches the design.
- The existing weekly brief deck (`caseload-deck-027.html`) is the visual reference. Do not modify it.
- The spec for this plan is [`docs/superpowers/specs/2026-04-22-exports-design.md`](../specs/2026-04-22-exports-design.md). Open it alongside this plan.
