# Persistent Brain — Rollout

The Weekly Digest system itself as a product: voice-dump → persistent MD
brain → weekly brief + on-demand exports. Currently single-operator
(Joel). Rollout idea: grassroots — prove it works for one teammate,
then let it spread.

## Invariants

- Not a tool launch. A grassroots pattern.
- The brain is personal — same as the voice. Whoever uses it owns
  their folder.
- If it sticks with one person, it sticks with ten.

## Off-ramp

One teammate runs a full Friday cycle end-to-end (intake → brief)
and gets value from the output.

## Next move

Pick a candidate teammate for the mock profile.
