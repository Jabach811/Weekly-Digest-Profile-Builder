Ramping Blocked byADP · Deferral report │ RoundTwo · pain points known │ Liquidation~ 2 weeks

Why this round is easier

  • Population mostly already in our system
  • ADP records clean everywhere except deferrals
  • Operator knows exactly where the deferral report lives
  • New ADP rep appears ready to move

Immediate next moves

  1. Email new ADP rep — request deferral report
  2. Confirm whether a base file is needed
  3. Stage the three-bucket split for liquidation
The workaround
ADP cannot reliably identify who is still in default once marked "in default" within the min → (max − 1) window. Four-step play:
  1. Load everyone at current % — out of default
  2. Identify the ambiguous set (in default, inside the window)
  3. Client notifies those participants: auto-escalate won't apply; locked at current % unless they self-change
  4. Protects participants first; firm by extension
